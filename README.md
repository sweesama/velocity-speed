# Velocity — 极简实时物理测速与高程仪

> 对标 Apple Design Award 工具美学（参考 *Lumy* 与 *实时高度表*），基于硬件级 GNSS 卫星多普勒频移（Doppler Shift）与三轴惯导（IMU）滤波融合的全场景纯离线测速工具。

---

## 核心特性

1. **全场景真实硬件测速（零玩具仿真，100% 物理真速）**
   - 无需手动选择交通工具，自适应覆盖 **民航客机（0–950+ km/h）**、**高速铁路（350 km/h）**、**汽车驾驶**、**自行车骑行** 与 **跑步运动**；
   - 支持 **km/h**、**Knots（航空节）**、**mph（英里/时）**、**m/s（米/秒）** 一键无缝切换，并在高速区间（$\ge 250\text{ km/h}$）自动解算平流层标准大气 **马赫数（Mach）**。

2. **针对竞品核心痛点的物理滤波算法**
   - **CEP 精度门控与静止死区滤波（Stationary Deadband）**：当硬件未返回多普勒速度或处于室内静止状态时，自动通过水平定位误差半径（CEP）过滤坐标微漂移，彻底杜绝桌面静止时乱跳速度或虚增里程；
   - **牛顿力学极限跳变抑制（Plausibility Spike Filter）**：结合手机三轴加速度计（IMU），自动拦截进出隧道、高架桥多径反射引起的单帧伪极速尖峰；
   - **重力基线分离算法（High-Pass Gravity Blocker）**：分离静态手持倾角重力分量，真实测算加速时的水平推背感 G 值与 **0–100 km/h / 0–200 km/h** 冲刺用时；
   - **WGS-84 空间几何海拔**：直接解算卫星空间三角几何高程与垂直升降率（VSI），彻底穿透飞机客舱人工增压（约 2000m）限制，真实呈现万米巡航高度。

3. **双形态精密仪表 + 光学 HUD 投影**
   - **极简巨幕模式（Minimal）**：居中超细等宽巨幕数字（60fps 物理惯性平滑插值）+ 60 秒实时速度轨迹流线 + 经典三联高对比指标；
   - **精密罗盘模式（Gauge）**：60 刻度动态点亮表盘 + 自适应量程（0–60 / 160 / 400 / 1000）+ 360° 真北航向旋转环；
   - **挡风玻璃 / 舷窗 HUD 镜像模式**：支持纯白、航空绿光、夜航琥珀三色温切换，仅镜像翻转核心读数区域，顶部控制栏保持正向易读。

4. **高清测速认证海报与标准 GPX 1.1 航迹导出**
   - 内置 1080×1350 高清 Canvas 离线渲染引擎，自动绘制本次行程的速度剖面曲线、峰值速度、推背感 G 值、最高海拔与时间印记；
   - 支持一键导出 1Hz 采样的标准 `.GPX` 航迹文件，可直接导入 Google Earth、Strava 或 Garmin Connect；
   - 自动将有效行程归档至本地历史档案（100% 本地存储，零云端上传）。
